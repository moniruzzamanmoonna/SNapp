## Features
- **Automatic capture:** saves each new slide, cropped to the slide. Skips duplicates and pauses while a video plays.
- **Capture Now:** one click saves the current screen.
- **Class schedule:** set your class times once, and capture starts and stops on its own.
- **Phone remote:** scan a QR code to capture from your seat and see recent slides (local Wi-Fi only).
- **Google Drive backup (optional):** slides go to *My Drive › SNapp › date*. Offline? They upload later.
- **Quiet in the tray:** no pop-ups. Can launch at Windows startup.

## Install
1. Download **SNapp-Setup.exe** from the [latest release](https://github.com/moniruzzamanmoonna/SNapp/releases/latest).
2. Run it. No admin rights needed, and it adds Start Menu and Desktop shortcuts.
3. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**. SNapp isn't code-signed yet.

Prefer no installer? Download **SNapp.exe** (portable) and run it directly.

Slides are saved in `Documents\LectureSnap\<date>\`. Uninstalling keeps your slides.

## Checksums
